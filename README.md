## General Setup

All projects in this repository are developed and tested using **Visual Studio 2022** with the following configuration:

- **Platform Toolset:** v143  
- **Language Standard:** ISO C++20 Standard (/std:c+ +20)

### How to Run
1. Open the solution/project file (`.sln`) in **Visual Studio 2022**.  
2. Ensure the configuration is set to **Debug | x64**.  
3. Build the project (`Build > Build Solution`).  
4. Run the project (`Debug > Start Without Debugging` or press `Ctrl+Shift+B`).
